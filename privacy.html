Privacy Policy

Hermes Workspace Agent — last updated 6 October 2026

1. Who this covers

Hermes Workspace Agent is a private, single-user tool. Its only user is its owner, Tianyu Liu, and it runs locally on that owner's own computer. There are no other users, no accounts, and no multi-tenant service. This policy explains what the tool does with Google user data that the owner chooses to grant it access to.

2. Google user data accessed, and why

The owner grants access through Google's OAuth consent screen. Each scope below is requested for one purpose, and is used only at the owner's explicit request or by an automation the owner has configured:

ScopeDataPurpose
gmail.readonly Email messages and settings Reading, searching and summarising the owner's own mail on request.
gmail.modify Email labels and read state Triage: labelling, archiving and marking the owner's own mail as read.
gmail.send Outgoing mail Sending replies and messages that the owner has authored or approved.
calendar Calendar events Reading and creating the owner's own calendar events on request.
drive Drive files Reading and managing the owner's own files on request.
contacts.readonly Contacts Resolving names to addresses when the owner asks it to.
spreadsheets Spreadsheet contents Reading and updating the owner's own spreadsheets on request.
documents Document contents Reading and updating the owner's own documents on request.

3. How the data is used

  • Only to carry out tasks the owner asks for, on the owner's own account.
  • Data is processed locally on the owner's computer.
  • No data is sold, rented, or shared with third parties.
  • No data is used for advertising, profiling, or training machine-learning models.
  • No human other than the owner reads the data.

4. Storage and security

OAuth refresh and access tokens are stored in a local credential file on the owner's computer, readable only by the owner's operating-system account, and are used solely to call Google APIs as described above. Message and file content is fetched on demand; it is not copied into any external database or server controlled by a third party. Google API traffic uses HTTPS.

5. Retention and deletion

The tool keeps only the OAuth tokens it needs, for as long as the owner keeps the connection active. Revoking access at myaccount.google.com/permissions immediately invalidates them; deleting the local token file does the same. Any cached content can be deleted from the owner's machine at any time.

6. Sharing

Google user data is not transferred to any third party. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Changes

If this policy changes, the updated version will be posted at this URL with a new "last updated" date.
